# Start Here

The one-page handoff. Claude reads this at the start of every session and rewrites it at the end, so anyone (you, Claude, an editor) can pick the book up cold.

## Where it stands
Not started. Run `/mind-map` in Claude's Code tab with this folder open.

## Next in order
1. `/mind-map`: talk through everything you know about the book, in any order, and Claude puts it on one page.
2. `/setup-book`: Claude turns the map into the outline and fills in CLAUDE.md, the Book Brief and the chapter notes.
3. `/voice-capture`: Claude studies how you write and builds your voice skill.
4. First draft: add your first material to `Research/` and run `/ingest-source`, `/ingest-interview` or `/ingest-author`, or start with `/dictation-questions`. Then each chapter goes on through interviews, research, refining and a check (the seven steps in [[How We Write This Book]]).
