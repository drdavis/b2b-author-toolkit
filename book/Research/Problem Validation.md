# Problem Validation

Is the book's problem worth a book? `/validate-problem` scores it against four tests using what interviewees and readers actually said, and updates the score as evidence comes in.

## Scorecard

| Test | Question | Rating | Best evidence |
| --- | --- | --- | --- |
| Painful | Does it hurt enough that people describe it with feeling? | | |
| Pervasive | Do many people in the reader group have it, not just one or two? | | |
| Priority now | Is it near the top of their list this year? | | |
| Pay | Have they spent money or time trying to fix it? | | |

Ratings: Strong, Plausible, Mixed, Unproven.
